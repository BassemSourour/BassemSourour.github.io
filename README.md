# bassemsourour.github.io

My personal portfolio and co-op work term reports.

**Live at [bassemsourour.github.io](https://bassemsourour.github.io)**

## About

I'm a Bachelor of Computing co-op student at the University of Guelph.
This site collects my work term reports and the things I've built. It's
plain HTML and CSS with a little vanilla JavaScript — no framework, no
build step, no dependencies.

## Structure

```
index.html         Portfolio home
work-term-1.html   Work Term 1 — Reunion Coffee Roasters, Summer 2026
styles.css         Shared styles
images/            Photos and screenshots
```

Each work term gets its own page and a card on the home page.

## Running locally

Open `index.html` in a browser. That's it.
